# Getting Started

1. **Click 'Use this Template'** and open it in Github.

2. Open the **Actions** tab in your GitHub repository and select **Initialize Template** from the sidebar. If it doesn't show up, add a single empty line at the start of the file `.github/workflows/main.yml` and commit it and check again.

3. **Run the workflow** and fill in the required inputs:

    * **Package:** e.g. `com.anaphan.mymod`
    * **Mod ID:** e.g. `mymod`
    * **Mod Name / Main Class:** e.g. `MyMod`

4. Once the workflow finishes, open the project in IntelliJ IDEA.

5. You're ready to start developing! The workflow should have renamed packages, updated project metadata, and removed the template files automatically
